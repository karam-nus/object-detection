# Measurement scripts

The scripts behind every number this book measured itself (as opposed to numbers copied from papers and
documentation, which carry their source). They need the `ultralytics` package (the book used 8.4.174),
`onnx`, `onnxruntime`, `opencv-python`, `pycocotools` and the companion `odlab` package in `code/`.

Set `ODBOOK_WORK` to a scratch directory (default: `./work` in the repository root). Scripts that need
model weights expect them in `$ODBOOK_WORK/weights/` (`yolo26n.pt`, `yolo11n.pt`, `bus.jpg`, `zidane.jpg`
from the Ultralytics assets releases), and the INT8 and auto-label studies expect COCO128 in
`$ODBOOK_WORK/datasets/coco128/`. Run the Ultralytics-based scripts from a directory where `ultralytics`
is importable.

| Script | What it measures | Chapter |
|---|---|---|
| `shapes.py <model.yaml>` | Per-layer output shapes and parameter counts at 640 | 29 |
| `flops_by_res.py <model.yaml>` | Conv MACs and parameters grouped by feature-map stride | 29 |
| `intensity.py <model.yaml> …` | Conv FLOPs, activation traffic and arithmetic intensity | 44 |
| `metric_compare.py` | Ultralytics' built-in mAP vs the COCO protocol on identical predictions | 33 |
| `bootstrap_ci.py` | Bootstrap confidence intervals of mAP for 50/200/1,000 images | 33 |
| `seed_lr.py <lrs> [threads]` | TinyYOLO learning-rate × seed sweep (12 epochs) | 32 |
| `export_study.py` | ONNX exports of YOLO26n/YOLO11n with each `nms` option: shapes, nodes, operators, size | 36 |
| `postproc_study.py` | CPU pipeline timings: preprocess, inference, post-processing; head agreement | 36, 46 |
| `int8_study.py` | ONNX Runtime static INT8 PTQ, whole graph vs float head output, on COCO128 | 45 |
| `autolabel_study.py` | YOLOE-26 text-prompt auto-label quality vs human COCO128 labels | 49 |

The accuracy–latency figure of Chapter 34 is generated by `../plot_pareto.py` and Appendix C by
`../build_model_index.py`, both from `assets/data/detectors.json`.
